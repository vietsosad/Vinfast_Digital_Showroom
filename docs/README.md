# Tài liệu môn Kiến trúc phần mềm

Bộ tài liệu chuẩn của sản phẩm backend:

1. [PHASE1_PRESENTATION.md](PHASE1_PRESENTATION.md) — nội dung thuyết trình 5–7 phút: bài toán, nghiệp vụ, vấn đề dễ thấy, tổ chức mã nguồn, framework, yêu cầu kỹ thuật.
2. [PHASE1_ACCEPTANCE.md](PHASE1_ACCEPTANCE.md) — đối chiếu yêu cầu đề bài với bằng chứng và việc còn lại.
3. [API.md](API.md) — endpoint, payload, quyền, trạng thái nghiệp vụ và mã lỗi; [openapi.json](openapi.json) là đặc tả OpenAPI 3.1 máy đọc được.
4. [ARCHITECTURE.md](ARCHITECTURE.md) — phân tầng, transaction, dữ liệu, bảo mật và ADR.
5. [KAGGLE_LOAD_TEST.md](KAGGLE_LOAD_TEST.md) — quy trình đo tải có thể lặp lại; kết quả baseline ở [loadtest/results/phase1-baseline/](../loadtest/results/phase1-baseline/README.md).
6. [PHASE_PLAN.md](PHASE_PLAN.md) — kế hoạch Pha 1 và thí nghiệm chất lượng Pha 2.
7. [PHASE1_BACKEND_ASSIGNMENT.md](PHASE1_BACKEND_ASSIGNMENT.md) và [PHASE1_BACKEND_REPORT_ONE_PAGE.md](PHASE1_BACKEND_REPORT_ONE_PAGE.md) — phân công.

`evidence/` chứa ảnh minh chứng (Swagger, CI, Docker health) khi nộp bài.
