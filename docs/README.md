# Tài liệu môn Kiến trúc phần mềm

Bộ tài liệu chuẩn của sản phẩm backend:

1. [PHASE1_ACCEPTANCE.md](PHASE1_ACCEPTANCE.md) — đối chiếu yêu cầu đề bài với bằng chứng và việc còn lại.
2. [API.md](API.md) — endpoint, payload, quyền, trạng thái nghiệp vụ và mã lỗi; [openapi.json](openapi.json) là snapshot máy đọc được.
3. [ARCHITECTURE.md](ARCHITECTURE.md) — phân tầng, transaction, dữ liệu, bảo mật và ADR.
4. [KAGGLE_LOAD_TEST.md](KAGGLE_LOAD_TEST.md) — quy trình đo tải có thể lặp lại.
5. [PHASE_PLAN.md](PHASE_PLAN.md) — kế hoạch Pha 1 và thí nghiệm chất lượng Pha 2.
6. [PHASE1_BACKEND_ASSIGNMENT.md](PHASE1_BACKEND_ASSIGNMENT.md) và [PHASE1_BACKEND_REPORT_ONE_PAGE.md](PHASE1_BACKEND_REPORT_ONE_PAGE.md) — phân công.

`evidence/` chứa ảnh minh chứng (Swagger, CI, Docker health) khi nộp bài.
